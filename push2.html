🛠️ 분석에 사용한 데이터·기술

일봉·주봉 차트는 yfinance 데이터를 matplotlib으로 그렸습니다.
기술적 지표는 MA·RSI·MACD·스토캐스틱·볼린저밴드·ATR을 pandas와 numpy로 계산했어요.
수급은 네이버 증권 API로 받았고, 종가는 yfinance와 네이버 실시간 API로 교차확인했습니다.
분기 실적은 yfinance 분기 손익계산서, 밸류에이션은 네이버 모바일 API 기준이에요.
공급계약 세 건은 DART 원문을 직접 열어 계약명·금액·상대방·지역·기간·대금 조건을 확인했습니다.
차트 패턴과 데자뷰 통계는 자체 휴리스틱이며 재미용입니다.
